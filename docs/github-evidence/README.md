# Archived GitHub verification evidence

`run-43478940011/` is the artifact and metadata downloaded from the successful
[GitHub Actions run](https://github.com/lazyinspirit/workflow-engines/actions/runs/43478940011)
for source commit `cce0eae51b895ab80dace76438a4b0da04fe0415`.

`verification.json` binds every checked package input, the exact source commit,
the two accepted independent review receipts and all nine command exits/logs.
The input and log hashes were compared with the local files and all match.
`SHA256SUMS` covers the downloaded records and compressed logs, excluding itself.
`github-actions.log.gz` is the complete successful run's console log.

`cancelled-checkout-run-43478655246.log.gz` belongs to an earlier run cancelled
during checkout, before Lean ran. It is not a failed or successful proof check.
Its replacement uses a sparse checkout, with identical scientific sources.

These archived files do not expire with GitHub's artifact retention period.
They are records of checking, not a substitute for the Lean source, the pinned
dependencies, the reviewed mathematical interpretation or reproduction.
