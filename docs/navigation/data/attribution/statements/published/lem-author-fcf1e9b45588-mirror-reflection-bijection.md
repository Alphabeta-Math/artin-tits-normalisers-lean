Let $W\leq\mathrm{GL}(E)$ be an essential finite real reflection group and $(W,S)$ the chamber-wall Coxeter system of [lem-author-fcf1e9b45588-chamber-wall-rank](item-lem-author-fcf1e9b45588-chamber-wall-rank). Put $T=\{wsw^{-1}:w\in W,\ s\in S\}$. Then $T$ is exactly the set of linear reflections in $W$, and $t\mapsto\operatorname{Fix}(t)$ bijects $T$ with $\mathcal A(W)$. In particular $|\mathcal A(W)|=|T|$.
