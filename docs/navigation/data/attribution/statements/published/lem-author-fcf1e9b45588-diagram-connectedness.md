Suppose $\mathcal A(W)$ is an irreducible finite real reflection arrangement on $E$, with $\dim E>1$, in the sense of [lem-author-fcf1e9b45588-invariant-metric-essentiality](item-lem-author-fcf1e9b45588-invariant-metric-essentiality). Its chamber-wall Coxeter system from [lem-author-fcf1e9b45588-chamber-wall-rank](item-lem-author-fcf1e9b45588-chamber-wall-rank) has connected Coxeter diagram in the convention of [def-coxeter-data-artin-tits-normalisers](item-def-coxeter-data-artin-tits-normalisers). In particular, if $\dim E=3$, this system has connected rank three.
