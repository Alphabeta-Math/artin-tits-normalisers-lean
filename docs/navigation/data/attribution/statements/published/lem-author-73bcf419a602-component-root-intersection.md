Use the arbitrary-rank geometric representation of [def-coxeter-data-artin-tits-normalisers](item-def-coxeter-data-artin-tits-normalisers) and the orbit definition $\Phi_L=\{w\alpha_i:w\in W_L,i\in L\}$ from [def-parabolic-subgroups-artin-tits-normalisers](item-def-parabolic-subgroups-artin-tits-normalisers). Let $I\subseteq\Gamma_0$, $a\in\Gamma_0\setminus I$, $K=[I,a]$, $J=K\setminus\{a\}$, $V_L=\operatorname{span}_{\mathbb R}\{\alpha_i:i\in L\}$ and $D=\Phi_{I+a}\setminus\Phi_I$, with connected-component notation from [def-connected-support-artin-tits-normalisers](item-def-connected-support-artin-tits-normalisers). Vectors have finite support, even if the vertex set is infinite. Then $\Phi_K\cap\Phi_I=\Phi_J$. In particular $\Phi_K\setminus\Phi_J\subseteq D$. No rank-finiteness assumption is needed.
