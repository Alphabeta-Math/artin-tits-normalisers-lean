Let $E=\Theta_J$ and $u\in\mathrm{Cone}(J)^\circ$ in the finite-dimensional topology of [[def-relative-cone-artin-tits-normalisers]]. There exists an ambient Euclidean ball $B$ centred at $u$ such that $B\cap E\subseteq\mathrm{Cone}(J)$, only finitely many members of $\mathcal H^J$ meet $B\cap E$, and every ambient root hyperplane meeting $B\cap E$ contains $u$. There are $v,v^\prime\in B\cap E$ on no relative hyperplane with $v^\prime=2u-v$. If $\dim E>0$, choose $v\ne v^\prime$, so $u$ is interior to $[v,v^\prime]$; if $E=0$, take $v=v^\prime=u$. No claim is made that every root hyperplane meeting $B\cap\mathrm{Cone}$ contains $u$.
