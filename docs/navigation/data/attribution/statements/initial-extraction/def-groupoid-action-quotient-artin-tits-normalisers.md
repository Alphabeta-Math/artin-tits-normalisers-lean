An action of $N$ on $\mathcal G$ is a homomorphism $N\to\mathrm{Aut}(\mathcal G)$. If the action is free on objects, $\mathcal G/N$ has object orbits $[x]$ and morphisms $[\alpha]:[x]\to[y]$ represented by $\alpha:gx\to g^\prime y$ for $g,g^\prime\in N$. To compose $[\alpha]$ and $[\beta]$, choose the representative $\beta^\prime$ with source the target of $\alpha$ and set their composite to $[\alpha\beta^\prime]$.
