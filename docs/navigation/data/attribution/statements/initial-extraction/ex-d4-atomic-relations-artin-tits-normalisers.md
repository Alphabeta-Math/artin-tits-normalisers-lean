The source gives $st\cdot v\cdot ts=vt\cdot s\cdot tv$ and $s\cdot tv\cdot st=tv\cdot ts\cdot v$. The first lifts to the paths $(e,2)\to(st,1)\to(stv,1)\to(stvts,2)$ and $(e,2)\to(vt,4)\to(vts,4)\to(stvts,2)$. The second lifts to $(vts,4)\to(vt,4)\to(e,2)\to(st,1)$ and $(vts,4)\to(stvts,2)\to(stv,1)\to(st,1)$. These run around the same hexagonal face. All atomic braid relations in this example have length two or three, corresponding to squares and hexagons.
