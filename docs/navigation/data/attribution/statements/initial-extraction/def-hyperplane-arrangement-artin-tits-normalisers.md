A hyperplane arrangement $(T,\mathcal H)$ consists of a convex subset $T$ of a real vector space and a possibly infinite set of linear hyperplanes, each meeting $T$. Restriction to a convex $T^\prime\subseteq T$ retains just hyperplanes meeting $T^\prime$, still denoted $(T^\prime,\mathcal H)$. Local finiteness means every point of $T$ has a relatively open neighbourhood meeting only finitely many hyperplanes.
