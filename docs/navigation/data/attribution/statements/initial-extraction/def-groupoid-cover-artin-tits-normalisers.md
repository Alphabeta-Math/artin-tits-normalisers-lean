A functor $F:\widetilde{\mathcal G}\to\mathcal G$ is a covering if every morphism $\alpha:x\to y$ has a unique lift from any chosen $\widetilde x\in F^{-1}(x)$, including a unique lifted target. A covering is universal if its vertex groups are trivial, equivalently each morphism set upstairs is a singleton. Deck transformations are automorphisms $\phi$ with the strict equality $F=F\circ\phi$. A cover is normal when deck transformations act transitively on a fibre (equivalently every fibre).
