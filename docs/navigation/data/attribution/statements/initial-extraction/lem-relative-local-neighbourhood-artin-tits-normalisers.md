The source argument asserts that for $u\in\mathrm{Cone}(J)^\circ$ there is a sufficiently small ambient ball $B$ centred at $u$ such that hyperplanes of $\mathcal H$ meeting $B\cap\mathrm{Cone}$ contain $u$, and $B\cap\Theta_J$ lies in $\mathrm{Cone}(J)$. It uses density of the relative hyperplane complement to choose $v$ in this ball on no relative hyperplane, and asserts the same for $v^\prime=2u-v$, with $u$ interior to $[v,v^\prime]$.
