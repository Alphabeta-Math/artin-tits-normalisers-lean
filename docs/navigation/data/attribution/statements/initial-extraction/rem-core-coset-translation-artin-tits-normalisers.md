For an atomic coset set $I=L-a$. The core condition forces $a^\prime=\iota_{[I,a]}(a)=\iota_{I+a}(a)$ in the finite $W_{I+a}$ setting. The minimal representative of $W_{L-a}w_LW_{L-a^\prime}$ is $v_{a,I}=w_Iw_{I+a}$ rather than $w_L$. Taking minimal representatives identifies core cosets $W_IxW_K$ with $\mathrm{Hom}_{\mathcal{BH}}(I,K)$, atomic cosets with the generators, atomic reduced expressions with standard expressions, and Ko’s atomic braid relations with Definition 4.18. The article identifies [25, Theorem 1.8] with its atomic Matsumoto theorem in the finitary setting, and claims the latter removes the requirement that $W_{I+a}$ be finite.
