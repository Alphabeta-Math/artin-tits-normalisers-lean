In spherical type let $D_H(C)$ be the open half-space of $H$ containing chamber $C$. Define $X_C=\{x+iy\in\mathcal X_J^{\mathbb C}:\forall H\in\mathcal H^J,\ x\in H\Rightarrow y\in D_H(C)\}$. For adjacent $C,C^\prime$ separated by $H_0$, the article writes $X_{C,C^\prime}=\{x+iy\in\mathcal X_J^{\mathbb C}:x\in D_{H_0}(C),\ \forall H\in\mathcal H^J,\ x\in H\Rightarrow y\in D_H(C)=D_H(C^\prime)\}$; define $X_{C^\prime,C}$ by interchanging the chambers.
