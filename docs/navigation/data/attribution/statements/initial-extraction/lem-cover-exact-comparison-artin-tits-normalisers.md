In spherical type, with $\mathcal D_J$ based at $(e,J)$, the source identifies $1\to\mathcal D_J\to(\mathcal D/N(W,J))_J\to N(W,J)\to1$ with the topological covering sequence. It also identifies it with $1\to\mathcal D_J\xrightarrow{\mathcal G}\mathcal R_J\xrightarrow{\psi}N(W,J)\to1$. For $\mu\in\mathcal R_J$, the lift from $(e,J)$ ends at $(\pi(\mu),J)$, so $\psi(\mu)=\pi(\mu)W_J$. Under $\mathcal R_J\cong N(A,J)$ this map agrees with $\overline\pi$.
