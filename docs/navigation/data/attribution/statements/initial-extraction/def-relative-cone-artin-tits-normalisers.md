For $J\subseteq\Gamma_0$, define $\mathrm{Cone}(J)=\mathrm{Cone}\cap\Theta_J$ and take $\mathrm{Cone}(J)^\circ$ in $\Theta_J$. Put $\Phi^J=\{\alpha\in\Phi:\Theta_J\not\subseteq H_\alpha\}=\Phi\setminus\Phi_J$ and $\Phi^J_{\pm}=\Phi^J\cap\Phi^{\pm}$. The relative arrangement is $\mathcal H^J=\{H\cap\Theta_J:H\in\mathcal H,\Theta_J\not\subseteq H\}=\{H_\alpha\cap\Theta_J:\alpha\in\Phi^J_+\}$. For $J=\varnothing$ this recovers the Coxeter arrangement.
