# Concrete Artin presentation wrappers

`ArtinNormalisers/Artin/Basic.lean` imports the pinned, vendored Tau Ceti
`ArtinGroup` presentation, its canonical generator, and its proved surjection
onto the Coxeter group. Local proofs identify the image of every subgroup
generated by selected Artin generators with the corresponding Coxeter
parabolic. The pure subgroup is the actual kernel.

The final source SHA256 is
`b9160bf44e7ae7aca86f7757158f742d5ca33c1eec527215e8238bd38a47c1da`.

Actual commands, run from the Lake package directory:

- `lake env lean ArtinNormalisers/Artin/Basic.lean` initially failed because
  the pinned mathlib Coxeter object file had not been built. See
  `compile-attempt-1.log`.
- `lake build Mathlib.GroupTheory.Coxeter.Basic` succeeded. See
  `dependency-build.log`.
- After the root agent vendored Tau Ceti, the revised wrapper file compiled
  with one unused-simp-argument warning. See `compile-attempt-2.log`.
- After removing that argument, `lake build ArtinNormalisers.Artin.Basic`
  succeeded without warnings. See `final-build.log`.
- `lake env lean evidence/full-development/basic/Signatures.lean` succeeded.
  `signatures-and-axioms.log` records all 13 public signatures and the
  transitive axioms of all six proved theorems; each reports exactly
  `propext`, `Classical.choice`, and `Quot.sound`.

`independent-presentation-draft.lean.txt` preserves the initial independent
presentation draft, superseded before final compilation so the development
uses the same Artin presentation as the Matsumoto supplier. It is evidence,
not an imported scientific module or a claimed compiled result.

These checks concern the concrete Artin definitions and projection only.
They do not by themselves prove the normalizer lifting theorem or Lemma 2.8.
