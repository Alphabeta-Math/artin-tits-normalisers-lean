## Literal mathematical semantics and applications

- **`SemilocallySimplyConnected.Basic`** defines semilocal simple connectivity by actual loops in a neighborhood nullhomotopic in the ambient space. It does not require the neighborhood itself simply connected. Shrinking/open-neighborhood lemmas, local/simple/strong-local-contractibility implications, discrete and product instances all respect that distinction. The locally contractible implication uses a genuine nullhomotopic inclusion. This is an appropriate local condition for the actual complement; it is not global simple connectedness or asphericity.
- **`TubeNeighborhood`** constructs finite compact-open path tubes from segment sets that are path-homotopy-trivial in the ambient space and path-connected vertex neighborhoods. Existence uses a real path partition, openness uses compact segment constraints, and rung paths plus pasted homotopies prove endpoint-fixed homotopy and moving-basepoint conjugacy. The segment properties are explicit hypotheses on tube data, proved when consumed in the semilocal construction. This concerns path-space topology, not the arrangement chamber tubes from M3.
- **`SemilocallySimplyConnected.On`** proves the open/fundamental-group/path characterizations, pullback under an injective induced π₁ map, and the necessary unbased local path-homotopy-trivial neighborhoods using actual local path connectedness and conjugation. Compact-open homotopy classes are open, so fixed-endpoint path-class quotients are discrete under the stated local hypotheses. The final clopen-family theorem correctly handles moving basepoints through tube conjugacy. These results do not make the full variable-endpoint universal cover discrete.
- **`UniversalCover.BasedPath`** defines actual continuous maps from the interval based at x₀ as a compact-open subspace, with genuine evaluation continuity. It explicitly builds terminal deformations, proves endpoint openness using finite compact-open constraints, builds continuous initial-segment families and appended initial segments, and relates path components of endpoint preimages to endpoint-fixed path homotopy. The refined-tube argument proves those components open under local hypotheses. No topology is replaced by a discrete or indiscrete shortcut.
- **`UniversalCover.Basic`** defines points as actual endpoints together with fixed-endpoint path-homotopy classes from x₀, then equips them with the topology coinduced from the compact-open based-path surjection. It is not the naive sigma topology. It proves quotient-map and equality/homotopy criteria, actual projection continuity and openness, range equal to the actual path component, and sheets via saturated based-path components. The sheet surjection, pairwise disjointness, exhaustion, openness and injectivity proofs have the required path-connected/path-homotopy-trivial neighborhood hypotheses. `fiberEquivFundamentalGroup` is explicitly only a type equivalence; it does not sneak in an opposite-group multiplication claim.
- **`SeparatedMap`** proves Hausdorff transfer for continuous separated maps (including covers), discreteness/finiteness of locally injective fibers, and equality of continuous sections over a preconnected set under local injectivity/separatedness. Its Hausdorff and compactness conditions are in the actual statements. These are legitimate support lemmas; the broader section API is not an asphericity assertion.
- **`IsLocalHomeomorph`** transports local path connectedness by actual local inverse charts. The germ/open-image, local-deck identity, fiber-sum, product, pullback, embedding-restriction and descent results preserve their explicit local, continuity, separation and compact-support hypotheses. I read those broader proof bodies too. The universal-cover consumer uses the local-path-connectedness transfer; the fiber-sum API is not needed for that conclusion.
- **`UniversalCover.Covering`** proves the actual projection is evenly covered using the constructed sheets. It does not assume the base path connected: points outside x₀'s path component may have empty fibers, explicitly handled. Initial segments prove path connectedness of the total path-class space. The actual lifted-path endpoint theorem, concatenation cancellation and covering injectivity on path homotopies prove simple connectedness. The universal lifting property is restricted to a simply connected, locally path-connected source with a chosen compatible lift. **None of these conclusions states the universal cover contractible or weakly contractible in higher dimensions.** The based-path space has a useful initial-segment family, but this file does not assert it descends to a global contraction of the path-class cover.
- **`Topology.Homotopy.HomotopyEquiv`** proves genuine homotopy invariance of path components/connectedness, product/cylinder equivalences and homotopy-inverse identities. It uses actual homotopies and their traces, not mere fundamental-groupoid equivalences. Contractible product factors are explicit inputs.
- **`HomotopyGroup.HomotopyEquiv`** constructs generalized-loop homotopies along actual free-homotopy traces, includes basepoint transport/casts, proves both round-trip bijections and actual homotopy-group isomorphisms for finite index types, and deduces `HomotopyGroup.subsingleton_of_contractibleSpace` from a real homotopy equivalence to a point. Its `[Finite N]` and, for group structures/transport, nonempty/decidable/fintype assumptions are in scope. Empty N is also correctly covered by the subsingleton instance. It does not infer trivial higher groups from trivial π₁.
- **`Topology.Algebra.Module.LocallyContractible`** uses balanced neighborhoods and genuine star-convex contractions, translated to each point, to prove every real topological vector space strongly locally contractible. It requires the actual additive/module/continuity structures; local convexity and finite dimension are not extra assumptions. The standard subspace/product topology of the actual relative complement meets these hypotheses, and existing openness gives the corresponding local property on the complement.
